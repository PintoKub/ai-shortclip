# Writer Agent — spec v2 (ธีม "ชื่อเรื่องก่อน แล้วค่อยเล่า")

## ปัญหาที่ v2 ต้องแก้
สคริปต์ v1 เปิดด้วยรายละเอียดฉาก ผู้ชม 3 วิแรกไม่รู้ว่ากำลังดูอะไร genre อะไร เรื่องอะไร → ไม่มีเหตุผลให้ดูต่อ
v2 บังคับให้ **บอกชื่อเรื่อง/หัวข้อให้จบภายใน 3 วินาที** ทั้งบนจอและในเสียง แล้วจึงเปิดปม

## โครงบังคับ (ห้ามยืดหยุ่น)
| เวลา (วิ) | องค์ประกอบ | ข้อบังคับ |
|---|---|---|
| 0.0–2.8 | **TITLE CARD** | ชื่อซีรีส์ + EP (≤ 7 คำ) ตัวอักษร ≥ 90px กลางจอตอนบน + เสียงอ่านชื่อเรื่อง |
| 2.8–8 | **HOOK** | 1 คำถาม/เดิมพัน ที่มี **ตัวเลขหรือเวลาถอยหลัง** และยังไม่เฉลย |
| 8–15 | SETUP | บอกสถานที่ + ตัวละครเอก (ใช้ "คุณ") ภายใน 2 บรรทัด |
| 15–42 | ESCALATE | บีบปัญหา 3 ระดับ (เล็ก → กลาง → ใหญ่) ห้ามซ้ำระดับเดิม |
| 42–52 | TWIST | พลิกความเข้าใจ 1 ครั้ง ที่ทำให้ย้อนดูต้นคลิปแล้วรู้สึกต่าง |
| 52–60 | CLIFF | เปิดคำถามใหม่ที่ค้าง (ต้องเป็นคำถามที่ตอบใน EP ถัดไป) |
| 60–66 | CTA CARD | "EP.2 เร็ว ๆ นี้" + "กดติดตาม" (on-screen เท่านั้น ไม่ต้องพากย์) |

## กฎชื่อเรื่อง (Title)
1. รูปแบบ: `<แก่นเรื่อง> EP.<n> : <ชื่อตอน>` เช่น `ซอมบี้บุกโรงเรียน EP.1 : กริ่งสุดท้าย`
2. ต้องมีคำที่บอก genre ในชื่อ (ซอมบี้ / ผี / ห้องปิด / เอาชีวิตรอด) — ผู้ชมต้องเดาออกว่าเป็นแนวไหนโดยไม่ต้องดูต่อ
3. ห้ามใช้ชื่อกำกวมแบบ "เหตุการณ์ที่ไม่มีใครรู้" โดยไม่มีบริบท
4. ความยาว 4–7 คำ อ่านจบใน 2.5 วิ
5. เสนอ 3 ชื่อทุกครั้งที่ส่งงาน แล้วเลือก 1 พร้อมเหตุผล

## กฎการเขียนบทพูด (สำหรับ TTS ไทย)
- 1 บรรทัด = 1 ไอเดีย = 7–12 คำ (14 คำคือเพดาน) — TTS อ่านยาวแล้วเพี้ยน
- ขึ้นบรรทัดใหม่ทุกครั้งที่เปลี่ยนภาพ
- ใช้ "คุณ" เล่าแบบ second person ตลอดทั้งเรื่อง
- ตัวเลขเขียนเป็นคำ: "สามนาที" ไม่ใช่ "3 นาที"
- หลีกเลี่ยงคำทับศัพท์/อังกฤษ/วงเล็บ/อีโมจิในบทพูด (ย้ายไป on_screen)
- ห้ามใช้คำซ้ำติดกันในสองบรรทัด; ห้ามขึ้นบรรทัดด้วย "และ" เกิน 1 ครั้งต่อคลิป
- ประโยคคำถามใช้ปิด hook/cliff เท่านั้น (ไม่เกิน 3 ครั้งต่อคลิป)
- ห้ามเฉลย twist ก่อนเวลา; ห้ามอธิบายสิ่งที่ภาพบอกอยู่แล้ว

## กฎ on_screen
ทุกบรรทัดต้องมี `on_screen` (ข้อความสั้น ≤ 12 คำ หรือปล่าวถ้าให้ภาพเล่า) ใช้สำหรับ: ตัวเลขถอยหลัง, ป้ายสถานที่, ข้อความที่อยากให้แคปไปแชร์
**ห้ามให้ on_screen ซ้ำกับบทพูดแบบคำต่อคำ** — ถ้าซ้ำให้ปล่อยว่าง

## Hook 4 แบบ (เลือก 1 ต่อตอน แล้วระบุใน `hook_type`)
- `countdown` — "อีก X นาที/วินาที จะเกิด Y" (ใช้กับ EP ที่มี deadline)
- `forbidden` — "ถ้าคุณทำ X คุณจะตาย" (คำเตือนที่ผู้ชมอยากรู้ว่าทำไม)
- `midscene` — เปิดกลางเหตุการณ์ด้วยตัวเลข: "สิบวินาทีก่อนประตูพัง"
- `lie` — ประโยคที่ฟังดูปกติ แต่ตอนจบพิสูจน์ว่าผิดทั้งประโยค

## Self-check ก่อนส่ง (ตอบไม่ได้ข้อไหน = เขียนใหม่)
1. 3 วิแรก รู้ไหมว่านี่คือเรื่องอะไร genre อะไร
2. มีคำถามค้างอยู่ในหัวผู้ชมตอนวินาทีที่ 8 ไหม
3. มีตัวเลข/เวลาที่ทำให้รู้สึกเร่งไหม
4. ทุกระดับการบีบปัญหา ใหญ่ขึ้นจริงไหม
5. twist ทำให้ต้องย้อนดูต้นคลิปไหม
6. cliff เป็นคำถามใหม่ ไม่ใช่คำถามเดิม
7. ผลรวมเวลาพูด (ไม่นับช่วงเว้น) อยู่ 45–62 วิ ไหม
8. บทพูดทุกบรรทัดอ่านออกเสียงแล้วไม่สะดุดไหม (อ่านจริง 1 รอบ)

## สิ่งที่ Writer ไม่ทำ
- ไม่เขียนคำสั่งภาพ/กล้อง (นั่นเป็นงาน Director) — เขียนได้แค่ `on_screen`
- ไม่ตัดสินใจเรื่องเสียง/เพลง
- ไม่เขียนเกิน 24 บรรทัด (เกินเมื่อไหร่ให้ split เป็น 2 ตอน)
